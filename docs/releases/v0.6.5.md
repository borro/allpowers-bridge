# ALLPOWERS Bridge v0.6.5

- Reduce each board's public firmware ZIP from about 165 MB to about 0.8 MB by excluding the large generated source/object and relinking kit from installation downloads.
- Keep the firmware images, board manifest, license texts and notices in each package. Add `FIRMWARE-SOURCES.md` with the exact GitHub project commit, pinned dependency source URLs and SHA256 checksums, and rebuild/modification instructions.
- Update package manifests to list and hash exactly the included files. Retain the internal source matching and offline relinking checks during builds, and add regression checks for compact archives, source directions and unchanged firmware segments.
- Update the release download description and all four project overviews. This release changes packaging, not firmware logic, USB descriptors, partitions, history compatibility or the maintenance/update mechanism. Existing releases remain unchanged.
