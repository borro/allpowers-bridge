# ALLPOWERS Bridge v0.7.1

- Reduce Widget CPU use with cached graph geometry, static card layers, coalesced history updates and a reusable native desktop image buffer. Keep continuous graph animation at approximately 30 frames per second, with the final frame published immediately.
- Replace the Windows USB HID worker's frequent polling with read-completion events and explicit feature/retry deadlines. Preserve bounded draining, cancellation, operation identities and resource cleanup.
- Keep new Widget history samples in memory for immediate display and CSV export, then save them in one synchronized transaction every 60 seconds. Apply disk retention cleanup with each batch and save the remaining samples on normal exit. **An abrupt termination or power loss can lose the last minute of samples; a disk error can extend that window.** Monitor and service persistence remain unchanged.
- Preserve history ordering, clock rollback, session and board provenance, retention limits and imported archives. Retain accepted samples after a failed batch for retry and expose buffered sample counts and flush errors in diagnostics.
- Consolidate portable telemetry, archive and UPS logic in the shared core; calculate HID response CRC once per response. Expand fuzz inputs and coverage-preserving synthetic corpora.
- Strengthen native Windows tests for HID readiness and retry timing, graph/cache invalidation, desktop resource reuse and recovery, and buffered history transactions, failure recovery and shutdown. Validate the new behavior with targeted mutations alongside the project's portable mutation, coverage, sanitizer, memory and packaging checks.
