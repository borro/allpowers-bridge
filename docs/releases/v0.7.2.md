# ALLPOWERS Bridge v0.7.2

- Reduce Monitor chart work by retaining unchanged input and caching continuity links and visible geometry shared by all three series. Preserve peaks, gaps, epoch ordering, tooltips, zoom, pan and display scaling.
- Coalesce Monitor interface refreshes and avoid updating unchanged controls, styles and hidden diagnostic tables. Keep history collection and chart data current while pages are hidden, and refresh diagnostics immediately when opened.
- Buffer new Monitor local history samples in memory for immediate display and CSV export, then save them in one synchronized transaction every 60 seconds. Run retention cleanup with that batch and save the remaining samples on normal exit. **An abrupt termination or power loss can lose the last minute of samples; a disk error can extend that window.** The optional service keeps its existing persistence behavior.
- Preserve station, board and session provenance, imported archives and existing settings. Expose buffered sample counts and persistence errors in diagnostics, with tests for transaction rollback, retry and shutdown failures.
- Add regression tests and targeted mutations for chart cache invalidation, unchanged styles, diagnostic catch-up and buffered history shutdown. Verify identical chart images across 32 combinations of data size, view mode and display scaling.
