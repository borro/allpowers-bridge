# ALLPOWERS Bridge v0.6.4

- Add Bluetooth disconnect diagnostics for both adapter boards: retain the last eight disconnects with the raw stack reason, local-close intent, connection context and packet ages, and expose them in Monitor's USB diagnostics. Records remain in RAM until reboot; BLE reconnection behavior is unchanged.
- Speed up exporting embedded license notices on Windows by avoiding a separate disk synchronization for every file while retaining complete writes and atomic replacement.
- Make Monitor and Widget offline self-tests wait for history and rendering readiness, improving reliability on busy Windows systems. Expand regression tests for IPC, USB serial, history transfers, firmware rejection paths and Windows integration failure handling.
- Add blocking C++ static analysis, workflow checks, Linux/Windows coverage, mutation testing, BLE/CDC fuzzing, sanitizers and Valgrind memory checks to CI. Release publication requires the complete check set to pass.
- Run builds and analyzers in parallel, use four compiler jobs for Qt and product builds, trim dependency caches and the Qt development SDK, and publish concise per-job results with retained diagnostic reports.
- Publish the pinned C/C++ dependency inventory to GitHub Dependency Graph with source revisions, checksums, provenance and notice links. CI summaries and artifacts include a clickable inventory; WDK uses its native NuGet identity.
- Improve release retries for existing version tags without unnecessary workflow permission checks.
