# ALLPOWERS Bridge v0.5.3

- Made USB archive export more reliable across retries, cancelled requests and client restarts, with operation identifiers that reject stale responses.
- Fixed serial status scheduling and replacement of an active export request; archive output and live status share a coordinated output controller.
- Added compatibility checks for archive wire formats, verified export completion and history storage checks before firmware rollback.
- Expanded regression coverage for Windows recovery, history, CLI and atomic export paths, and strengthened CI firmware inventory checks.
