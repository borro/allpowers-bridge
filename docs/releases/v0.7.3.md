# ALLPOWERS Bridge v0.7.3

- Use the ESP32 ROM CRC32 routine and a compile-time table on the PC, preserving wire/archive CRCs. Send HID archive fragments in bounded batches with a short active yield; retain the idle delay and existing USB/maintenance contracts.
- Reduce screen traffic with small dirty rectangles and a single selected SPI transaction per address window and payload, at the existing 20 MHz. Retain full-frame fallback when the optional PSRAM shadow is unavailable.
- Speed up graph rendering with exact cached age thresholds, direct raster spans, conservative repeated-pixel coalescing and reuse of unchanged coordinates. Prepare graph history in one reverse pass, retaining overlap filtering, ages, gaps and unknown-time boundaries. Preserve history/NVS formats and station selection.
- Add optional PC logic workloads and on-board timing, paired comparisons, task stack watermarks and USB page selection. **Ordinary firmware disables profiling, temporary benchmark buffers and remote page control.** Keep the maintenance update interface available in both builds.
- Add independent image, ring and snapshot regression checks. Same-input Waveshare measurements found 2.44× faster panel preparation/transfer, 1.30× faster snapshot preparation and a further 9.47% reduction in graph raster time from coordinate reuse; these measure specific workloads, not universal refresh rates. See [methods and limits](../profiling.md).
- Retain 702 additional synthetic fuzz inputs after the completed eight-hour campaign and coverage-preserving minimization, with provenance and replay evidence.
