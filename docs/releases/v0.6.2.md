# ALLPOWERS Bridge v0.6.2

- Smaller Windows downloads: Monitor, Widget and static Qt are optimized for size, and packaged EXEs are compressed with UPX 5.2.1.
- Development EXEs remain uncompressed, and builds keep incremental relinking without IPO/LTO.
- Packaging checks the compressed applications' versions, offline startup, license notices and embedded driver before creating release archives.
