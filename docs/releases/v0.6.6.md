# ALLPOWERS Bridge v0.6.6

- Replace the nested `licenses.zip` and duplicate top-level notices in each board's firmware download with a regular `licenses/` directory. Identical full texts are stored once, with a component-to-license table in `README.md` and a machine-readable `components.json` inventory.
- Select components from the actual firmware link map instead of collecting licenses from every SDK example, test and compiler language. Preserve the original copyright, permission and NOTICE records in `NOTICES.md`, with references to their source files.
- Pin the exact NimBLE source revision used by the ESP-IDF Bluetooth stack, retain its NOTICE file, and include the terms for the linked TinyCrypt implementation and TLSF allocator.
- Hash every file in the license directory in the firmware manifest. Reject packages with missing referenced licenses or copyright records, duplicate full texts, unsafe paths or nested archives; retain the source matching and offline relinking checks for both boards.
- This release updates packaging, attribution and build tooling. Firmware logic, USB descriptors, partitions, stored history and the maintenance/update mechanism are unchanged.
