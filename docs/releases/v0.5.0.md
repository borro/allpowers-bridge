# ALLPOWERS Bridge v0.5.0

- Added a standalone desktop Widget for live telemetry, combining USB board history and current readings in its power graph.
- Monitor can use USB telemetry and the board archive, with a choice of data source; improved dropdown rendering after native popup animation.
- Added an experimental Windows UPS driver, shared service and local IPC. The optional driver remains unsigned and unverified in a VM.
- Upgraded the build to Qt 6.12 and C++23, added ROM-only board maintenance tooling and automated publication of verified release assets.
