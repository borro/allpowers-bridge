# ALLPOWERS Bridge v0.7.0

- Replace runtime USB CDC/COM telemetry with a dedicated, versioned HID collection. Monitor and Widget can read the same adapter independently without a background process or an additional telemetry driver. Preserve the system UPS HID collection and the service HID path into the ROM bootloader for firmware updates.
- Add request identifiers, checked response fragments and two independent frozen archive snapshots so concurrent clients can read diagnostics and history without sharing a response cursor. Bound queues, snapshot lifetimes and archive transfers; retain priority for UPS reports.
- Introduce persistent boot epochs and the AHP3 history format. Synchronize board time from Windows, preserve epoch and uptime information, and display archive and current readings in both time and epoch charts. Undated records remain available in the epoch chart and are omitted from the time chart.
- Improve board selection labels, reconnect handling and archive-read feedback. Disable the read button while an export is running, and retain local history, imports and USB mode settings.
- **Compatibility:** update the firmware and Windows applications together. The new applications require HID telemetry and do not fall back to runtime COM; old firmware is reported as requiring an update. Legacy archive formats are no longer supported, and incompatible board statistics are reset. ROM bootloader COM remains available for maintenance; runtime console commands and the 1200-baud bootloader trigger are removed.
- Add persistent Windows runtime diagnostics and expand HID, history, clock-boundary and multi-client tests. Add HID wire/server fuzzing and strengthen mutation tests, coverage checks, static analysis and memory checks.
- Consolidate CMake verification, parallel Git hooks and CI checks, with coverage thresholds, isolated packaging inputs and source-archive rebuild verification for the static Windows applications and both firmware targets.
