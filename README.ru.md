# ALLPOWERS

Телеметрия станций ALLPOWERS по BLE: общее ядро, две платы USB-ИБП и монитор
Windows. [English](README.md).

| Версия | Подключение | Возможности |
| --- | --- | --- |
| Waveshare ESP32-S3-LCD-1.47 | BLE Central → USB Device | HID-ИБП, экран, история, диагностика, RGB |
| Pocket-Dongle-S3 0.96 N16R8 | BLE Central → USB Device | HID-ИБП, компактный экран, история, диагностика |
| Windows Monitor | Обычный Bluetooth компьютера / Qt WinRT | Показания, графики, диагностика; без драйвера ИБП |

Ядро распознаёт 17 названий моделей и три семейства протокола. Отображение
USB-ИБП реализовано для R2500 V2. Другие профили показывают доступные поля,
не выдумывая неподдерживаемые значения. Некоторые станции принимают одного
BLE-клиента: перед подключением приложения отключите соединение платы.

![Монитор Windows с демонстрационными данными](docs/images/windows-monitor.png)

Продукт написан на C++17. Python остался только в инструментах сборки, тестах
и обслуживании; в Windows-пакете нет Python. Нативный интерфейс использует
Qt Widgets, отдельный поток SQLite и ограничение отрисовки графика по ширине
экрана. Есть масштабирование колёсиком, перемещение по времени, точные значения
под курсором, независимое скрытие линий, обычная/логарифмическая шкала и возврат
к текущему моменту.

## Структура

`core/` — протокол, сессии и C ABI v1; `firmware/` — общая прошивка и два
профиля плат; `apps/windows/` — нативный монитор C++17/Qt. Тесты и очищенные фикстуры — в
`tests/`, сборка и обслуживание — в `tools/`, примеры настроек — в `config/`.
Реальные идентификаторы хранятся только в игнорируемом `.local/`.

## Сборка в Windows и Linux

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/), Git и
Python 3.11 для инструментов сборки; в Windows также MSVC 2022 C++ Build Tools и Windows 11 SDK. Из корня репозитория:

```sh
uv sync --locked
uv run --locked python tools/build.py test
uv run --locked python tools/build.py setup
uv run --locked python tools/build.py all
```

Отдельные цели: `core`, `waveshare-147`, `pocket-096`, `windows`.
`all` собирает ядро и обе платы; в Windows также упаковывает приложение.
`setup` загружает Arduino CLI 1.5.1 с проверкой контрольной суммы и ставит
ESP32 Core 3.3.11, а в Windows — также Qt 6.8.3 MSVC. Готовую установку можно указать, скопировав
`config/arduino.example.json` в `.local/arduino.json` и заменив пути.
Автоматическая установка CLI поддерживает Windows/Linux x86-64.

Для ядра используются CMake Presets, Ninja и Zig 0.13. Python-зависимости и
инструменты закреплены в lock-файле. После первой сборки доступны также
`uv run cmake --build --preset dev` и `uv run ctest --preset dev`.
У каждой платы своя временная копия скетча. Сборка не трогает устройства,
BLE-соединения и исходники продукта.

Промежуточные файлы — в `build/`, образы и манифесты — в
`dist/firmware/<board>/`. Приложение — в `dist/windows/AllpowersMonitor/`,
рядом ZIP с контрольной суммой. Команда
`uv run --locked python tools/build.py clean` удаляет только результаты сборки.
EXE собирается в Windows. Приложение Linux пока не реализовано.

## Запуск и платы

В Windows запустите `dist/windows/AllpowersMonitor/AllpowersMonitor.exe`. Подключение выбирается явно.
Настройки, история и журналы — в `%LOCALAPPDATA%/AllpowersMonitor`.
Для диагностики путь переопределяется через `ALLPOWERS_DATA_DIR`.

Плата сохраняет выбранную станцию в NVS; без сохранённой станции открывает
список устройств. Одиночное BOOT переключает экраны, двойное открывает список.
В списке одиночное нажатие перемещает выбор, двойное или удержание подтверждает.
RESET остаётся аппаратным сбросом.

Прошивка — отдельное действие с проверкой конкретной платы. Перед записью
прочитайте [восстановление](docs/recovery.md). USB-дескрипторы, разделы памяти
и команда обслуживания `BOOT-R2500!!` сохранены.
